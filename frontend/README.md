# StudentHub - Frontend

React + Vite frontend for the StudentHub Enterprise Student Management Portal.

## 🚀 Tech Stack
- **React 19**
- **Vite 6**
- **Lucide Icons**
- **Executive Vanilla CSS Design System**

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
The application runs on `http://localhost:5173` and proxies API requests (`/api`) to the backend on `http://localhost:8080`.

### Production Build
```bash
npm run build
```
The built static files will be located in the `dist/` directory.
